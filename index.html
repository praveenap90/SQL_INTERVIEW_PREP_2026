EDA Analysis in Snowflake

  
A staged walkthrough of how to explore an unfamiliar dataset in SQL: know what is in the tables, validate it, then answer business questions with window functions and reusable views. Interviewers often ask "how would you approach a new dataset?", and this is a worked answer you can run yourself.

About the data. TPC-H is a synthetic benchmark dataset that ships with every Snowflake account. Its values are generated and fairly uniform, so do not expect dramatic skew. The value here is the method, which transfers directly to real data.

In an interview. Narrate these five steps in order and name one query for each. Say what result would worry you, such as a mean far above the median or orphan keys, and what you would do next.

Experiment questions come up in analyst and data science interviews: how do you design a test, check it was run properly, read the result and decide? This walkthrough does it all in SQL for a green versus grey checkout button.
